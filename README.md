# Netflix Data Analysis

A data analysis project focused on exploring Netflix movies and TV shows to identify useful insights, trends, and patterns.

## Features

- Analyze Netflix movies and TV shows
- Explore content by genre
- Analyze movies and TV shows by release year
- Identify popular genres
- Compare movies and TV shows
- Analyze content ratings
- Visualize data using charts

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Dataset

The project uses Netflix titles data containing information such as title, type, genre, release year, rating, country, and other content-related details.

## Purpose

This project was created to practice data cleaning, data analysis, and data visualization using Python.
